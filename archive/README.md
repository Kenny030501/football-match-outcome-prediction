# Archived portfolio v1

`portfolio_pipeline_v1.py` and `portfolio_metrics_v1.json` preserve the first
leakage-corrected portfolio reconstruction. That version used one chronological
80/20 split, Bet365 pre-closing odds, a static 2015 stadium table, and a broader
model comparison.

The current project entrypoint is the third-party market probability audit in
`src/football_audit/`. The archived files are not part of the current result or
build-vs-buy recommendation.
